◆ Why the speed gap? The Architecture
Muse Glimmer — Dense
all parameters active per token
32.3B active
Every expert "brain" engages on every step → maximal capacity, higher FLOPs/token → slower but more faithful tool-following.
Qwen 3.6 — MoE
sparse, only ~3B active per token
~3B active / 35B total
Gating routes each token through a tiny expert slice → far fewer FLOPs/token → much faster inference, at a small reliability cost.
🎯
The deciding task — a 3-step chain search → read → calculate. Glimmer executed every step literally [search, read, calculate]. Qwen skipped the calculate call and answered itself — right answer, but it shortcut the tool plan.
